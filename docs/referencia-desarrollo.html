Stack y arranque

Backend FastAPI + Uvicorn (Python 3.11+) con ODM Beanie sobre PyMongo asíncrono; frontend React 18 + TypeScript + Vite + Tailwind. Una sola base MongoDB 7.x, multi-aplicación por el campo aplicacion_id.

app/main.py :: lifespan()
startup: init_db() → bootstrap() → iniciar_scheduler(). shutdown: detener_scheduler() → cerrar_db(). Middleware (externo→interno): CORS → GZip(min 1024 B) → routers. Si existe web/dist monta /assets y sirve index.html como fallback SPA.
app/db.py
init_db() abre AsyncMongoClient(settings.mongo_url) e inicializa Beanie con ALL_DOCUMENTS (27 modelos) y allow_index_dropping=True. cerrar_db() cierra el cliente.
Arranque local: arrancar.bat (crea venv, instala deps, genera api/.env, instala/arranca MongoDB, abre backend en :8000 y frontend en :5173). Producción: deploy/publicar-iis.bat — IIS sub-app /SistemaIntegrado con HttpPlatformHandler → Uvicorn.

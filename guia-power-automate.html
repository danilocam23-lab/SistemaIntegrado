1. Resumen de endpoints disponibles

GET /api/integracion/entregas

Devuelve un array plano donde cada objeto es una entrega pendiente de un requerimiento en estado ESTIMACION APROBADA ENTREGA PENDIENTE, con fecha comprometida del mes actual hacia atrás. Requerimientos sin entregas pendientes en ese rango se omiten.

ParámetroTipoRequeridoDescripción
aplicacionstring (query)NoCódigo de squad. Si se omite, devuelve todas las aplicaciones.
GET /api/health

Verifica que el servidor esté activo. No requiere autenticación.

2. Autenticación (API Key)

El endpoint de entregas usa autenticación por API Key. Se envía como header HTTP en cada petición: 

Header:  X-API-Key: <tu_clave_configurada>

-- Ejemplo real:
X-API-Key: si-powerautomate-2026-cambia-esta-clave
⚠️ Importante: La API Key se configura en el archivo .env del servidor con la variable API_KEY. Cámbiala antes de usar en producción.
💡 Tip: El endpoint /api/health NO requiere API Key. Úsalo para verificar conectividad antes de configurar la autenticación.

7. Manejo de errores

Código HTTPSignificadoQué hacer
200 ✅ Éxito Procesar el JSON normalmente
401 ❌ API Key inválida Verificar que el header X-API-Key coincida con el valor en .env
503 ⚙️ API Key no configurada El administrador debe agregar API_KEY=... en el archivo .env del servidor
500 💥 Error del servidor Revisar los logs del servidor; reintentar después
💡 Buena práctica: En Power Automate, activa «Configurar ejecución posterior» en la acción HTTP y agrega un paso de notificación si falla (es tiempo de espera agotado o error).

8. Preguntas frecuentes

¿Puedo probar el endpoint desde el navegador?

No directamente, porque requiere el header X-API-Key. Usa Postman, curl, o la documentación interactiva de FastAPI en https://tu-servidor/docs.

# Ejemplo con curl:
curl -H "X-API-Key: si-powerautomate-2026-cambia-esta-clave" \
       "https://reportescolombia.hitss.com/SistemaIntegrado/api/integracion/entregas"

¿Cómo filtro por un squad específico?

Agrega el parámetro ?aplicacion=CODIGO a la URL:

https://reportescolombia.hitss.com/SistemaIntegrado/api/integracion/entregas?aplicacion=epm-hitss

¿Qué pasa si un requerimiento no tiene entregas?

Se omite completamente de la respuesta. Solo aparecen requerimientos con al menos una entrega.

¿Por qué lt_hitss puede ser null?

Si el requerimiento no tiene un líder técnico HITSS asignado, o si la persona fue eliminada de la base de datos, el campo devuelve null.

¿Puedo usar la acción HTTP sin conector premium?

No. La acción HTTP requiere licencia Power Automate Premium (o per-flow). Alternativa: crear un Custom Connector si tu organización tiene uno disponible.

¿Cómo cambio la API Key?

Edita el archivo .env del servidor, cambia el valor de API_KEY, y reinicia el servidor. Actualiza el header en Power Automate.
